# 参与工具开发
欢迎大家参与工具开发，我这个low炮快初三了快没啥时间维护这个代码了
1. 将该仓库 fork 到个人账户中并 clone 到本地，新建新分支。
2. 在 tools 中新建一个文件夹，这是你的工具主要开发目录，文件夹名字随意，但其工具的启动命令取决于你工具的文件夹的名字（例如文件夹你写了了zhmzy，那么框架内启动你的工具的命令就是zhmzy）
3. 在刚创建好的文件夹中新建两个文件
  - main.sh (必要，这是命令输入后第一个启动的脚本)
  - info.ini (建议，里面主要是工具的基本信息，框架内输入 help 后会展示你的工具基本信息）
4. 那么你现在的文件夹结构应该长这样
```bash
tPaxs 根目录
└── tools
    └── <你起的文件夹名>
        ├── info.ini
        └── main.sh
```
5. 在 info.ini 中写下工具的基本信息，这里有一个模板供你参考
```conf
[tpaxs]
name=hello
desc=我是描述，这个工具只会输出helloworld
ver=v11.45
```
6. main.sh 是你的工具主文件，输入你的工具的启动命令后第一次启动就是该文件，接下来你可以编写脚本了
 - 注意：请在脚本第一行必须声明要使用的终端，必须是 bash。如下：
 ```bash
 #!/data/data/com.termux/files/usr/bin/bash
 ```
 - 你可以在脚本中调用 tPaxs 已经定义好的 global 脚本，调用后可以在你的脚本中使用 global 已经定义好的变量和命令，调用命令为 `source $PREFIX/lib/tpaxs/global`，如果需要的请将其放在脚本开头位置。具体global定义了什么，自己去仓库看罢
7. 写完后，将仓库重新commit并push到你个人仓库的新分支，然后提交pr。pr通过后你的工具就可以被别人使用力（喜
